# v5.0.3: browser demo dependency patch

The browser demo's lockfile, `web/package-lock.json`, moves Vite from 7.3.6 to
7.3.7 and source-map-js from 1.2.1 to 1.2.2, the lowest releases that clear
their published advisories. Vite 7.3.7 fixes GHSA-587h-7wmj-h5pm,
GHSA-698v-4r3x-3vcv and GHSA-r825-w8mm-5pxw in its bundled editor launcher and
GHSA-9jrq-w75r-8gcw and GHSA-rq7h-c2jc-7f22 in its development server;
source-map-js 1.2.2 fixes GHSA-68fv-2mgg-jv7q, a denial of service when parsing
a crafted indexed source map. These advisories concern the development server
and the build toolchain, not the static files the built demo serves. No other
locked package moves.

The gateway's Python dependencies are version ranges in `pyproject.toml`, with
no lockfile. Resolved for Python 3.12 on 2026-10-25 they gave 32 pinned
packages, and neither an OSV query nor pip-audit reported an advisory for any
of them.

The gateway, its resilience policies and its observability defaults are
unchanged apart from the version string. This release also contains the
documentation fix that replaced a dash in the v5.0.2 release note heading.
